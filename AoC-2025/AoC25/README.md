Advent of Code 2025. 
https://adventofcode.com/2025



1. do 10. dan, rešeni obe stopnji razen pri dnevu 10 je rešena samo 1. stopnja. Odgovori znotraj programa so logično poimenovani, kateri so za 1. in kateri za 2. stopnjo.

Za vsak dan posebej lahko prenesete vse datoteke iz tistega dneva, v README.MD, pri vsakem dnevu je na kratko opisan pristop k reševanju problema. Programi so bili napisani z objektnim programiranjem. Input.txt predstavlja vhodne podatke tistega dne.

ZAGON PROGRAMOV:
+ prenesite datoteko v svojo mapo na računalniku;
+ nadaljujte v terminalu;
+ ustvarite podmapo build 
+ postavite se v mapo build
+ zgradite datoteko s CMakeList.txt;
+ CMakeList vsebuje že kodo, ki input.txt prekopira v mapo Debug, da tega ni treba početi ročno. 
+ Program za zagon se nahaja v mapi Debug
+ Zaženite gesloX.exe (x predstavlja številko dneva)
